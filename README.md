# Dodo Pulse

Веб-приложение для просмотра отзывов гостей, поиска повторяющихся тем и обработки обращений управляющим.

## Что входит в MVP

- обзор количества отзывов, тональности и часто встречающихся тем;
- лента отзывов с поиском и фильтрами по источнику, пиццерии, теме, тональности и статусу;
- сортировка по дате и уверенности классификации;
- карточка отзыва с исходным текстом, категорией, объяснением классификации и уровнем уверенности;
- статусы «Новый», «На проверке» и «Обработан»;
- добавление отзыва с предварительным определением темы;
- выгрузка списка отзывов в CSV;
- REST API и хранение данных в `server/data/reviews.json`.

Классификация в этой версии основана на тематических словарях и правилах. Она помогает разложить обращения по темам, но не заменяет проверку человеком. Данные в начальном наборе демонстрационные. Внешние площадки и рабочая учётная система не подключены.

## Требования

- Node.js 18.18 или новее;
- npm.

## Запуск в режиме разработки

Из корневой папки проекта:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:5173`). Клиент обращается к API через dev-proxy. Сервер API работает на `http://localhost:3001`.

## Production-сборка и запуск

```bash
npm install
npm run build
npm start
```

После сборки сервер Express одновременно обслуживает API и React-клиент. По умолчанию приложение доступно на `http://localhost:3001`. Порт можно изменить переменной окружения `PORT`.

## Данные

Начальные записи хранятся в `server/data/seed-reviews.json`. При первом запуске они копируются в `server/data/reviews.json`. Все добавленные отзывы и изменения статусов сохраняются в `reviews.json` и остаются после перезапуска.

Чтобы вернуть начальный набор, удалите `server/data/reviews.json` при остановленном сервере и запустите приложение снова.

```text

  pages/        страницы приложения
  services/     клиент REST API
  utils/        форматирование данных
  App.jsx       состояние приложения и навигация
  styles.css    адаптивные стили
shared/
  classify.js   общие правила классификации
server/
  data/         начальные и рабочие данные
  index.js      REST API и раздача production-сборки
  store.js      чтение и сохранение данных
```
